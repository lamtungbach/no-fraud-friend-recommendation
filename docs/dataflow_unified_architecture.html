sequenceDiagram
    autonumber
    actor User as Người dùng (Client)
    participant RecEngine as PYMK Rec Engine (Bách)
    participant TwoHop as TwoHopCandidateGenerator
    participant Scorer as Topology Scorer (Adamic-Adar)
    participant API as FastAPI Router (/safe-filter)
    participant TrustService as TrustService (Linh)
    participant Cache as In-Memory Cache (RAM)
    participant Agent as TrustAgent (Explainable)

    User->>RecEngine: Yêu cầu gợi ý kết bạn cho User 100
    activate RecEngine

    %% Phần bạn Bách
    RecEngine->>TwoHop: generate(source_node=100)
    TwoHop-->>RecEngine: Danh sách 2-hop: [105, 308, 512, 888]

    RecEngine->>Scorer: score_candidates(100, [105, 308, 512, 888])
    Scorer-->>RecEngine: Điểm topo: 888 (3.5), 105 (2.8), 512 (2.4), 308 (1.9)
    Note over RecEngine: User 888 có điểm topo cao nhất do kết nối spam nhiều!

    %% Chuyển qua Bộ lọc An toàn
    RecEngine->>API: POST /api/v1/recommendations/safe-filter
{target_user: 100, candidates: [888, 105, 512, 308]}
    activate API
    API->>TrustService: filter_safe_candidates(100, [888, 105, 512, 308])
    activate TrustService

    %% Tra cứu Cache O(1)
    loop Với từng Candidate ID
        TrustService->>Cache: get(user_id) [Tra cứu O(1)]
        Cache-->>TrustService: {trust_score, p_bot, recommendation_tier}
    end

    Note over TrustService: - User 105: Tier 1 (Verified) -> GIỮ LẠI
- User 308: Tier 2 (Standard) -> GIỮ LẠI
- User 512: Tier 3 (Caution) -> LOẠI BỎ
- User 888: Tier 4 (Fraud/Bot, P_bot=92%) -> CHẶN NGAY!

    TrustService-->>API: SafeFilterResponse (clean: [105, 308], filtered: [888, 512])
    deactivate TrustService
    API-->>RecEngine: HTTP 200 OK (Danh sách an toàn đã lọc)
    deactivate API

    %% Xếp hạng cuối cùng
    RecEngine->>RecEngine: Score_final = Score_link * (Trust_score / 100)
    RecEngine-->>User: Hiển thị Top Bạn Bè An Toàn: [User 105, User 308]
    deactivate RecEngine

    %% Trường hợp Admin cần giải thích
    opt Admin kiểm tra lý do chặn User 888
        User->>API: POST /api/v1/trust/reason {user_id: 888}
        API->>Agent: inspect_and_reason(888)
        Agent-->>API: Reasoning Trace: ["Xác suất Bot 92% từ R-GCN", "Spam Mention cao"]
        API-->>User: HTTP 200 OK (Chi tiết vết suy luận)
    end
🧩 Đặc tả Chi tiết Từng Module Trong Luồng Dữ Liệu
Module / Tệp Nguồn Phân Hệ Input Data Output Data Vai trò & Thuật toán
src/data/canonical_graph.py Chung Raw Tensors (.pt) từ MGTAB CanonicalGraph Contract Chuẩn hoá 10.199 nodes, 7 relation types, 788 features độc lập với định dạng thô.
src/tasks/base_link_task.py Bách CanonicalGraph TaskGraph (Directed/Mutual) Xây dựng đồ thị bài toán liên kết có hướng hoặc proxy bạn bè tương hỗ 2 chiều.
src/split/leakage_mask.py Bách TaskGraph, Train/Val/Test Splits observed_graph Ẩn cạnh dương của tập kiểm thử để triệt tiêu hoàn toàn Data Leakage.
src/candidates/two_hop.py Bách source_node, observed_graph Set[candidate_nodes] Duyệt mạng lưới bạn của bạn: N(N(u)) - N(u) - {u}.
src/baselines/*.py Bách Cặp nút (u, v) Score_link(u, v) Tính toán độ mạnh liên kết dựa trên Adamic-Adar, Jaccard, Common Neighbors, Preferential Attachment.
src/trust/models.py Linh Node Features (788) + 7 Quan hệ cạnh Xác suất P_bot(v) ∈ [0, 1] Mạng nơ-ron đồ thị R-GCN 2 tầng chuẩn hoá lan truyền thông điệp phân loại Bot.
src/trust/scoring.py Linh P_bot, 4 Trụ cột tín nhiệm S_trust (0..100) & Tier Tính điểm tín nhiệm toàn diện và phân tầng 4 mức chính sách đề xuất.
src/trust/service.py Linh Danh sách Candidate IDs từ Bách SafeFilterResponse In-Memory Cache tra cứu O(1), gạn lọc ứng viên sạch (Tier 1 & 2), loại bỏ Tier 3 & 4.
src/trust/agent.py Linh user_id Reasoning Trace Tác tử suy luận đa bước giải thích lý do tài khoản bị gắn cờ hoặc cho phép gợi ý.

📐 Các Công thức Toán học Cốt lõi Trong Luồng:

1. Công thức Điểm Tín nhiệm 4 Trụ cột (Phần Linh):
S_trust(u) = 100 * G_auth(u) *
   [0.35 * S_auth + 0.25 * S_interact +
    0.25 * S_network + 0.15 * S_content]
2. Công thức Xếp hạng Bạn bè Cuối cùng (Hợp nhất Bách + Linh):
Score_final(u, v) = Score_link(u, v) * [S_trust(v) / 100.0]
(Trong đó: Score_link tính bởi Adamic-Adar hoặc Jaccard,
 và v bắt buộc phải thuộc Tier 1 hoặc Tier 2)
