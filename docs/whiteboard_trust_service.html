2. Cơ chế Đánh giá Tín nhiệm & Phân tầng

Điểm Tín nhiệm (S_trust)

Kết hợp xác suất Bot từ mô hình R-GCN và 4 trụ cột hành vi: 

S_trust = 100 * (1 - P_bot) *
  [0.35*S_auth + 0.25*S_interact +
   0.25*S_network + 0.15*S_content]
  • S_auth: Xác thực danh tính
  • S_interact: Độ lành mạnh tương tác
  • S_network: Độ sạch mạng lưới liên kết
  • S_content: Mức độ an toàn nội dung

Chính sách Phân tầng Quyết định

Phân tầng Tiêu chí Quyết định
Tier 1 S_trust ≥ 80, P_bot < 0.1 Cho phép (Verified)
Tier 2 S_trust ≥ 60, P_bot < 0.3 Cho phép (Standard)
Tier 3 S_trust 40..60 hoặc P_bot 0.3..0.5 Loại bỏ (Caution)
Tier 4 S_trust < 40 hoặc P_bot ≥ 0.5 Cách ly (Fraud/Bot)

3. Danh mục Endpoint REST API

Method Endpoint Mục đích
POST /api/v1/recommendations/safe-filter Lọc danh sách ứng viên kết bạn, loại bỏ Tier 3 và Tier 4
POST /api/v1/trust/batch Thẩm định và trả thông số tín nhiệm cho danh sách User ID
GET /api/v1/trust/{user_id} Tra cứu thông tin tín nhiệm của 1 User ID
POST /api/v1/trust/check Tra cứu thông tin tín nhiệm qua JSON request body
POST /api/v1/trust/reason Thẩm định chuyên sâu và sinh Reasoning Trace giải thích quyết định

4. Luồng Xử lý Endpoint /safe-filter (Core Flow)

Quy trình tiếp nhận request, tra cứu bộ nhớ và lọc ứng viên:

sequenceDiagram autonumber participant Caller as Caller (External) participant Router as FastAPI Router participant Cache as In-Memory Cache (RAM) Caller->>Router: POST /api/v1/recommendations/safe-filter Note over Caller,Router: Payload: target_user_id, candidate_user_ids: [105, 308, 512, 888] loop Với từng candidate ID Router->>Cache: Tra cứu hồ sơ (O(1)) Cache-->>Router: P_bot, S_trust, Tier alt Tier 1 hoặc Tier 2 Note over Router: Giữ lại (clean_candidates) else Tier 3 hoặc Tier 4 Note over Router: Loại bỏ (filtered_count + 1) end end Router-->>Caller: HTTP 200 OK (JSON Data) Note over Caller,Router: Output: clean_candidates: [105, 308], filtered_count: 2

Đầu vào (Request Body)

{
  "target_user_id": 100,
  "candidate_user_ids": [105, 308, 512, 888]
}

Được validate tự động bằng Pydantic schema (SafeFilterRequest).

Đầu ra (Response Data)

{
  "target_user_id": 100,
  "clean_candidates": [
    {"user_id": 105, "trust_score": 89.5, "tier": "TIER_1_..."},
    {"user_id": 308, "trust_score": 71.2, "tier": "TIER_2_..."}
  ],
  "filtered_count": 2
}

User 512 (Tier 3) và User 888 (Tier 4) đã được loại bỏ.
